How automatic code generation works

1. Select Class & Subject

Pick the relevant Class and Subject. Each code is strictly mapped to this pair.

2. Automatic Generation

The backend generates a collision-free, randomized unique key saved in SQLite.

3. Share with Students

Provide this code to your students for their verified registration and access.

4. Secure & Persistent

Codes remain safely recorded and associated with your teacher account permanently.
